## ⚡ Proyectos destacados.

### 🍽️ CaterLink
* **Descripción:** Sistema web integral de inventario y gestión de pedidos diseñado para pequeños negocios de catering y restaurantes, enfocado en reducir el desperdicio de alimentos (*mermas*) y optimizar el control financiero.
* **Tecnologías utilizadas y su aplicación:** Se utilizó `Angular` y `TypeScript` para construir una interfaz de usuario reactiva, impulsada en el backend por `Node.js` y `Express`. La persistencia de datos se gestionó modelando esquemas relacionales mediante `Prisma ORM` y `PostgreSQL`, mientras que el diseño visual se estructuró con `TailwindCSS`.
* **Funcionalidades Principales:** 
  * Panel de control con métricas e indicadores de rendimiento (*dashboard*).
  * Gestión centralizada de pedidos de clientes y control de stock de insumos.
  * Arquitectura full-stack robusta optimizada para entornos locales y producción.
* **Enlaces:** [Repositorio GitHub](https://github.com/joamrend/CaterLinkSoftware)

### 🌿 EcoRuta
* **Descripción:** Aplicación enfocada en la planificación y optimización de rutas ecológicas y sostenibles, diseñada para fomentar una movilidad eficiente y reducir el impacto ambiental en los desplazamientos urbanos.
* **Tecnologías utilizadas y su aplicación:** Implementada empleando `JavaScript` y `TypeScript` para la lógica del cliente, estructurada con `HTML5` y estilizada mediante `TailwindCSS`. Se integraron `APIs Geoespaciales` para el cálculo dinámico de trayectos.
* **Funcionalidades Principales:** 
  * Cálculo y visualización interactiva de trayectos de movilidad eficiente.
  * Enfoque en la sostenibilidad urbana y reducción de huella ambiental.
  * Interfaz optimizada y responsiva para una experiencia de usuario fluida.
* **Enlaces:** [Repositorio GitHub](https://github.com/joamrend/ecoruta)

### 📄 docxMareMioGenerator
* **Descripción:** Herramienta automatizada para la generación masiva y estructurada de documentos en formato Word (`.docx`), diseñada para agilizar reportes administrativos y operativos del entorno de MareMio.
* **Tecnologías utilizadas y su aplicación:** Desarrollada con `JavaScript`, `TypeScript` y `Node.js`, integrando librerías especializadas de manipulación de documentos para automatizar la creación de plantillas dinámicas en entornos de backend.
* **Funcionalidades Principales:** 
  * Automatización en la creación de archivos y reportes corporativos a partir de datos dinámicos.
  * Optimización de los tiempos de respuesta administrativos y estandarización de plantillas.
  * Integración fluida con flujos de trabajo de backend.
* **Enlaces:** [Repositorio GitHub](https://github.com/joamrend/docxMareMioGenerator)
